Manual Context Handoff Kit for ChatGPT Web · BẢN V15

Bộ chuyển giao context thủ công giữa các chat

Chat dài thì gấp chặng đã xong thành 1 block ngắn, cất vào repo GitHub private của bạn, rồi mở chat mới nạp lại bằng block đó. Chỉ có 3 bước ở dưới, 4 prompt để copy nguyên văn, và 1 form tạo block đã rút gọn.

V15 đổi luật của kit: form tự điền nhiều hơn (NN, ngày, version, status tự sinh từ sổ cấp ID và ngày hôm nay; session_id và số bản gói mới bạn tự ghi) và thu gọn các ô ít dùng. Vì luật đã đổi, mọi kết quả thử nghiệm của các bản trước không còn áp dụng — dùng bản này thì kiểm lại từ đầu.

Cách dùng — 3 bước

  1. Chat như bình thường

    Chat trong 1 chat cho tới khi một chặng việc đã khép lại (đã chốt xong một việc, khoảng 2.500–4.000 từ cả hỏi lẫn đáp) và chat bắt đầu dài. Chưa khép lại thì chưa gấp.

  2. Gấp ngay trong chat đó bằng Prompt A

    Copy đoạn chat của chặng ra, tẩy password / API key / thông tin riêng thành [REDACTED], rồi dán Prompt A nguyên văn vào chính chat đó kèm đoạn đã tẩy và sổ gấp. Model gấp thành 1 block, tự đẩy file block lên repo dữ liệu private và trả link commit — mở link đó kiểm lại file trước khi coi là xong. Cần tạo block bằng tay thì dùng form ở cuối trang.

  3. Mở chat mới bằng Prompt B

    Mở chat mới, dán Prompt B nguyên văn (kèm tin đầu tiên và 3 tin gần nhất). Model tự đọc các block đang current từ repo, nhắc lại bàn giao — kiểm xong mới làm tiếp. Chat cũ đổi tên [ARCHIVE] <dự án> <ngày>, giữ lại, không xóa. Đủ 8 block thì dùng Prompt D gộp; cần lại chi tiết cũ thì theo Prompt C.

Prompt B · Mở chat mới, nạp lại
